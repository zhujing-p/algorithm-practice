总结：

常见思考方向

1. 理解题意，明确输入输出
输入是什么？ 范围多大？（决定算法复杂度）

输出是什么？ 格式要求？是否有多个解？

有没有样例？ 手动模拟一遍，确认自己理解正确。

例如八皇后：输入 n (6~13)，输出前三个解的列号序列（空格隔开），最后输出解的总数。

2. 转化为计算模型
把题目描述变成计算机能处理的问题：

状态表示：用什么数据结构表示当前局面？（数组、向量、集合…）

约束条件：哪些是合法的，哪些是非法的？

目标：找到所有合法状态，或最优状态。

八皇后：状态是每行棋子的列号。约束：不同行不同列不同对角线。

3. 思考算法类型（分类讨论）
根据题目特征猜测可能用到的算法：

枚举所有可能 → 回溯/DFS（状态空间搜索）

最值/最优解 → 动态规划、贪心、二分答案

图论问题 → BFS/DFS、最短路、并查集

数学公式 → 直接推导、递推

八皇后：所有合法布局 → 回溯法（DFS + 剪枝）。

4. 设计状态转移与剪枝
如何从一个状态扩展到下一个状态？（例如：逐行放置）

如何剪枝？提前判断非法状态，避免深入。

用什么数据结构快速判断合法性？（布尔数组、哈希集…）

八皇后：每行尝试每列，用三个布尔数组 O(1) 判断冲突。

5. 确定递归/迭代结构
递归函数参数：当前处理到哪一行/哪一步

终止条件：找到完整解时记录/输出

回溯：恢复状态，尝试下一个分支

八皇后：dfs(row)，当 row == n 时找到一个解。

6. 处理输出格式与边界
按题目要求的顺序输出（字典序、大小序）

注意空格、换行

边界条件：n=0, n=1 等特殊情况
